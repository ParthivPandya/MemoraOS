## Limits

- The corpus is small and written by the same project that is being measured, and so are the questions. Treat this as an honest end-to-end check on real text, not as an independent benchmark.
- The held-out set is small (22 questions): differences of a few points are not significant.
- MemoraOS's temporal and contradiction machinery is largely idle on prose documentation: this run mainly measures retrieval, answer extraction and abstention on unstructured text.
- Mem0, Graphiti, Hindsight and Memorilla were not run.
