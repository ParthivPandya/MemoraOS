# Code of Conduct

We follow the spirit of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Our standard.** Be respectful and constructive. Welcome newcomers, assume good faith, give and accept feedback graciously, and focus on what is best for the project and community.

**Unacceptable behaviour.** Harassment, discrimination, personal or political attacks, trolling, publishing others' private information, and any conduct that would be inappropriate in a professional setting.

**Enforcement.** Maintainers may remove, edit or reject comments, commits, issues and contributions that violate this code, and may temporarily or permanently ban contributors. Report concerns privately to the maintainers through GitHub's reporting tools (or the contact listed on the repository profile). Reports are handled confidentially and fairly.

This code applies in all project spaces and when representing the project publicly.
